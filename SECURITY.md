# Reporte de vulnerabilidades

No publiques vulnerabilidades, credenciales expuestas ni datos sensibles en issues públicos o pull requests.

Envía el reporte de forma privada a los responsables del repositorio mediante los canales privados disponibles en GitHub. Si el repositorio no ofrece un canal privado habilitado, contacta directamente a un administrador del repositorio y comparte solo la información mínima necesaria para reproducir el problema.

Incluye la ruta o componente afectado, el impacto observado, pasos de reproducción con datos ficticios y una posible mitigación si la conoces. No incluyas contraseñas, tokens ni datos personales de usuarios reales.

El equipo confirmará recepción y coordinará la corrección antes de publicar detalles técnicos.
