# Seguridad

## Versiones con soporte

Este es un MVP académico en desarrollo. No se garantiza soporte de seguridad para versiones publicadas ni para el servicio de demostración.

## Reportar una vulnerabilidad

No publiques detalles de una vulnerabilidad en un Issue público. Usa la opción **Report a vulnerability** de la pestaña **Security** del repositorio en GitHub para iniciar un aviso privado. Si esa opción no está habilitada, contacta en privado al responsable del repositorio y comparte solo los detalles necesarios para reproducir el problema.

No incluyas contraseñas, tokens, datos personales ni datos reales de clientes en reportes, capturas o registros. El equipo confirmará recepción y acordará una forma de validar la corrección antes de divulgar detalles.
